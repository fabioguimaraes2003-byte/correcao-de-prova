Nome do sistema:

Sistema de Correção de Provas – Escola Legal

Objetivo do sistema:

O sistema tem como objetivo auxiliar no processo de correção de provas e no acompanhamento do desempenho dos alunos de uma turma.

O programa permite cadastrar um gabarito, cadastrar as respostas dos alunos, calcular automaticamente suas notas e apresentar informações estatísticas sobre o desempenho da turma.

O sistema foi desenvolvido na linguagem C, utilizando estruturas, funções, vetores, estruturas condicionais e estruturas de repetição.

Principais funcionalidades:

Cadastro do gabarito da prova;
Cadastro dos alunos;
Cadastro das respostas de cada aluno;
Validação das alternativas informadas;
Cálculo automático das notas;
Listagem geral das notas dos alunos;
Geração de relatório estatístico da turma;
Identificação da maior e menor nota;
Cálculo da média da turma;
Identificação da quantidade de alunos aprovados e reprovados;
Cálculo do percentual de aprovação;
Identificação da questão com maior quantidade de erros.

A prova possui 5 questões, sendo que cada questão correta vale 2 pontos, totalizando uma nota máxima de 10 pontos.

O sistema considera como aprovados os alunos que obtiverem nota igual ou superior a 7,0.

Tecnologias utilizadas:
Linguagem de programação: C;
Compilador/ambiente informado no código: Dev-C++;
Controle de versão: Git/GitHub;
Sistema operacional: compatível com Windows e sistemas Unix-like, considerando o comando utilizado para limpeza da tela.
